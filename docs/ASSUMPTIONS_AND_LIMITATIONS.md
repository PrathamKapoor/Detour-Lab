## 3. Known limitations of the current implementation

1. No real jurisdiction is encoded. Any statement about legal compliance is out of scope and must
   not be generated by the product.
2. No field survey, no imagery, no ML measurement. R2 items are deliberately not started.
3. Basemap: the demo renders canonical geometry on a deterministic offline SVG canvas. There is no
   aerial/road backdrop, by design (no tile licence has been verified).
4. Single-process SQLite persistence; no multi-user concurrency, no authentication, no RBAC
   (roles are an R2 item).
5. Optimiser, when built, is optimal **only within the enumerated candidate domain**.
6. Benchmark metrics, once produced, describe synthetic fixtures only and are not citywide
   accessibility accuracy (PRD §13.1).
7. Accessibility: automated axe-style checks plus one documented keyboard-only pass do not equal
   full WCAG 2.2 AA conformance, and must not be reported as such.
8. ReportLab PDF byte streams may embed nondeterministic metadata; reproducibility is asserted on
   the **canonical JSON manifest hash**, not on PDF bytes (MASTER_PROMPT §11).
